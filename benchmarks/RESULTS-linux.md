# Benchmark results (Linux)

Generated by `benchmarks/run-benchmarks.sh` (median of 7 runs, whole-process wall time including startup).

- Machine: Intel(R) Core(TM) i7-14650HX, Linux 6.18.33.2-microsoft-standard-WSL2
- GlowLang: `bin/glowlang` (GlowLang 1.11.0, commit bda0dbc)
- Python: Python 3.14.4

| Benchmark | GlowLang | Python | Python time / GlowLang time |
|---|---:|---:|---:|
| Fibonacci (sum fib 0..29) | 31 ms | 85 ms | 2.75x |
| Loop (1M additions) | 8 ms | 63 ms | 7.70x |
| Ackermann(3, 8) | 38 ms | 139 ms | 3.65x |
| N-Queens (N=10, objects) | 26 ms | 61 ms | 2.36x |
| Dijkstra (1000 nodes) | 40 ms | 116 ms | 2.89x |
| Lists + dict (1M push, 200k keys) | 70 ms | 189 ms | 2.70x |
| Strings (200k concat + split) | 34 ms | 47 ms | 1.40x |

A value above 1 means GlowLang finished faster. Both languages must print identical output for a row to count.
