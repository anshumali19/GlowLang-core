# Benchmark results

Generated by `benchmarks/run-benchmarks.ps1` (median of 7 runs, whole-process wall time including startup).

- Machine: Intel(R) Core(TM) i7-14650HX
- GlowLang: `bin\glowlang.exe` (commit 361670c + working tree)
- Python: Python 3.13.15

| Benchmark | GlowLang | Python | Python time / GlowLang time |
|---|---:|---:|---:|
| Fibonacci (sum fib 0..29) | 57 ms | 128 ms | 2.24x |
| Loop (1M additions) | 17 ms | 90 ms | 5.18x |
| Ackermann(3, 8) | 64 ms | 190 ms | 2.98x |
| N-Queens (N=10, objects) | 41 ms | 98 ms | 2.42x |
| Dijkstra (1000 nodes) | 77 ms | 174 ms | 2.26x |
| Lists + dict (1M push, 200k keys) | 110 ms | 253 ms | 2.31x |
| Strings (200k concat + split) | 48 ms | 72 ms | 1.48x |

A value above 1 means GlowLang finished faster. Both languages must print identical output for a row to count.
