# Benchmark results

Generated by `benchmarks/run-benchmarks.ps1` (median of 7 runs, whole-process wall time including startup).

- Machine: Intel(R) Core(TM) i7-14650HX
- GlowLang: `bin\glowlang.exe` (commit aaa2eda + working tree)
- Python: Python 3.13.15

| Benchmark | GlowLang | Python | Python time / GlowLang time |
|---|---:|---:|---:|
| Fibonacci (sum fib 0..29) | 58 ms | 131 ms | 2.27x |
| Loop (1M additions) | 17 ms | 90 ms | 5.23x |
| Ackermann(3, 8) | 64 ms | 182 ms | 2.82x |
| N-Queens (N=10, objects) | 41 ms | 97 ms | 2.38x |
| Dijkstra (1000 nodes) | 78 ms | 177 ms | 2.28x |
| Lists + dict (1M push, 200k keys) | 109 ms | 235 ms | 2.16x |
| Strings (200k concat + split) | 48 ms | 70 ms | 1.44x |

A value above 1 means GlowLang finished faster. Both languages must print identical output for a row to count.
