# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GlowLang, please report it responsibly.

Do NOT publicly disclose security issues before they have been reviewed and addressed.

Please include:

* a clear description of the vulnerability,
* affected components,
* reproduction steps,
* potential impact,
* and any suggested fixes if available.

## Contact

Security reports should be sent to the GlowLang maintainers directly.

Primary maintainers:

* Anshumali Sharma
* Anamika Mukherjee

Until an official security email/domain is established, security discussions should remain private and coordinated through approved repository communication channels.

## Supported Versions

Only actively maintained versions of GlowLang may receive security patches and updates.

## Responsible Disclosure

We appreciate responsible disclosure practices that help improve the safety and reliability of the GlowLang ecosystem.

Please avoid:

* public exploit releases,
* weaponized proof-of-concepts,
* or harmful disclosure practices.

## Scope

This policy applies to:

* compiler components,
* runtime systems,
* package management tools,
* official extensions,
* standard libraries,
* and officially maintained GlowLang ecosystem software.
