# ATTACHED DETAILED ARCHITECTURAL AUDIT (SOURCE OF TRUTH)

## 1. Verified Architectural Discrepancies
*   **Monolithic C Engine (`glowlang.y`)**: 
    The file `glowlang.y` is a 4,146-line monolith containing compiler, parser, VM interpreter (`run_bytecode`), native standard libraries, and GC routines.
*   **Legacy Interpreter (`run_bytecode_optimized.c`)**:
    Completely dead code, unreferenced in compilation configurations (the Makefile compiles `glowlang.tab.c` generated from `glowlang.y`).
*   **JIT Execution Status**:
    Gated/disabled for runtime compilation via `if (0) jit_compile(bc)` in `glowlang.y`. JIT operates only on manually warmed traces.
*   **Platform Limitations**:
    `jit.c` only emits valid machine code on x86_64; on ARM64 and WASM targets, it defaults to stubs setting `jit_failed = 1`.
*   **Mock Package Manager (`gdu`)**:
    `gdu.c` is a mock. It does not resolve dependencies or download packages; it simply writes mock print strings into files when a download fails.

## 3. Standard Library Vulnerabilities
*   **Missing Dictionary Methods**: Dictionaries in `web.glow` and `orm.glow` call `.has(key)` which crashes because VM dictionaries do not expose methods.
*   **Fake SQL Queries**: `db.glow` contains a hardcoded insert handler that parses only "Alice" and "Bob" to static records.
*   **http_client.glow**: Calls `http.request(...)` which is not registered in the standard library native bindings of `glowlang.y`.
*   **json_utils.glow**: Calls dictionary `.has` and string `.contains`, causing runtime crashes.

## 4. Phase 1 Correctness Violations to Fix
1.  **Parse Failure Exit Code**: `yyparse()` failure does not prevent return 0 from `main()`, masking syntax errors from the test suite runner.
2.  **Function Insertion Overwrite**: `func_table_add` lacks block braces, causing any hash collision to overwrite the function name and corrupt the binary.
3.  **SIMD Dispatch Fallthrough**: Adjacent labels from `l_OP_PACKED_MUL` to `l_OP_ITER_START` fall through directly to iterator instantiation.
4.  **Arena Memory Leak**: `arena_alloc` executes raw `calloc` for allocations > 1MB, but has no logic to track or free them during `arena_free_all()`.
5.  **GC Barrier Omissions**: `OP_SET_PROPERTY` does not trigger `gc_write_barrier`, causing missing references in generational collections.
6.  **Loop Control semantics**: `OP_STOP` exits functions instead of loops; `OP_SKIP` is implemented as an interpreter NOP.
