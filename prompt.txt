You are working on GlowLang, a high-performance natural-language-like programming language with a production-grade adaptive runtime architecture.

GlowLang already contains:

* Register-Based Virtual Machine
* Direct-Threaded Dispatch
* Aligned x86-64 JIT Compiler
* Type-Specialized JIT
* Polymorphic Inline Caches (PICs)
* Hidden Classes (Shapes)

The objective now is NOT to redesign the language.

* a complete production-grade runtime ecosystem
