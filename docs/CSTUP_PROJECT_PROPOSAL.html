Section 3: Project Overview & Alignment with CST UP Sectors
3.1 Problem Formulation

Modern computing infrastructure deployed across municipal offices, traffic surveillance grids, and digital governance portals in Uttar Pradesh is plagued by two structural vulnerabilities:

  • Software Memory Exploits (CWE-120, CWE-416): Traditional high-performance systems languages (C and C++) lack runtime boundary checks. Attackers exploit buffer overruns and dangling pointers to inject unauthorized machine code and hijack systems.
  • Extreme Runtime Bloat in Artificial Intelligence: Machine learning workflows rely heavily on Python wrappers (PyTorch, TensorFlow). These runtimes require multi-gigabyte installations and complex dynamic library chains, failing completely on low-spec standalone computers and embedded edge hardware.
3.2 Proposed Technical Solution

The project, GlowLang, designs and implements an indigenous systems programming language that integrates:

  1. Runtime Anti-Hacking Guardrails (Sector iv): Built-in memory boundary enforcement (GlowGuard) and structured data isolation (Kavach) that halt buffer overrun attempts automatically at runtime without crashing the operating system.
  2. Pure Native Transformer AI Engine (Sector xi): An attention-based neural network architecture implemented purely in native GlowLang tensors, achieving sub-2 millisecond inference with zero Python or external framework dependencies.
  3. Zero-Dependency Standalone Packaging: A self-contained portable binary distribution under 10 MB that executes out-of-the-box on standard Windows and Linux machines without requiring MSYS2, MinGW, or external toolchain setups.
Section 4: Current Status (Preliminary Proof-of-Concept)

To guarantee complete feasibility within the mandatory 3-month schedule, the team has already verified the theoretical foundations through a preliminary proof-of-concept (PoC):

  • Grammar & Token Formalism: Core lexical grammar rules and token precedence tables have been formally established.
  • Preliminary Scanner/Parser: A rudimentary parser capable of constructing Abstract Syntax Trees (AST) for basic scalar arithmetic expressions has been implemented.
  • Virtual Machine Design Study: Register-based VM opcode layouts have been architected to eliminate stack memory overhead.
Scope of Work to be Carried Out During the 3-Month CST UP Grant:
The grant period will be strictly dedicated to: (1) Integrating the GlowGuard boundary validation engine, (2) Implementing Kavach memory isolation, (3) Constructing the pure multi-head attention Transformer neural network, (4) Developing the portable zero-dependency packaging pipeline, (5) Benchmarking execution against C and Python, and (6) Authoring a Scopus/IEEE research paper.

5.1 Mathematical Formulation of Native Transformer Inference

The native deep learning engine implements self-attention without external libraries:

  • Scaled Dot-Product Attention: $\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{Q K^T}{\sqrt{d_k}}\right) V$
  • Numerically Stable Softmax: $\text{softmax}(z_i) = \frac{\exp(z_i - \max(z))}{\sum_{j} \exp(z_j - \max(z))}$
  • Multi-Head Attention: $\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O$
